# FixPay — Native Mobile Shell (Capacitor)

Capacitor wrapper that packages the **exact same FixPay frontend** shipped by
[`fixpay-pwa`](../fixpay-pwa) into installable **iOS** and **Android** apps.

> Parity with the PWA is structural: both builds compile the same `../fixpay-pwa/src`
> against the same Laravel backend. The only difference is runtime origin —
> the native build reads `VITE_API_URL` from [`.env.native`](./.env.native) instead
> of relying on same-origin `/api` proxying. Both deployments can therefore be
> served to different users with identical results.

## How it works

| Piece | Where | Why |
| --- | --- | --- |
| Shared UI / logic | `../fixpay-pwa/src` | single source of truth |
| Native web bundle | `../fixpay-pwa/dist` | produced by `vite build --mode native` |
| Native projects | `android/`, `ios/` | generated by `npx cap add <platform>` |
| Native env | `.env.native` | absolute `VITE_API_URL`, no mocks, no service worker |

`vite.config.ts` in the PWA excludes the Workbox/service-worker plugin and reads
`.env.native` from this folder whenever the build mode is `native`, so the hosted
PWA production bundle is untouched.

## Prerequisites

- Node 18+ and npm
- **Android:** Android Studio + Android SDK (API 34+)
- **iOS:** macOS + Xcode + CocoaPods (iOS cannot be built on Windows)

## Getting started

```bash
# 1. Install Capacitor tooling (first time only)
npm install
npm run add:android        # generates ./android
npm run add:ios            # generates ./ios  (macOS)

# 2. Point the app at your backend
#    Edit .env.native  ->  VITE_API_URL=https://<your-api>/api

# 3. Build the shared web bundle + copy it into the native projects
npm run sync:android       # or npm run sync:ios
```

## Daily workflow

```bash
npm run android            # build + sync + open Android Studio
npm run ios                # build + sync + open Xcode (macOS)
```

From Android Studio / Xcode, run the app on a device or emulator and log in —
the Laravel API must be reachable from the device and allow the WebView origins
(`capacitor://localhost` iOS, `https://localhost` Android) in
`fixpay-laravel/config/cors.php`.

## Production / release notes

1. `VITE_API_URL` in `.env.native` must point at the deployed Laravel API
   (HTTPS; cleartext is disabled).
2. Run `npm run sync:android && npm run sync:ios` in CI after `cap add`.
3. Sign with your Play Store keystore / Apple provisioning profile.
4. App identifiers: `com.fixpay.mobile` (change in `capacitor.config.ts` if the
   store package name differs from the PWA domain).

## What is intentionally NOT included yet

The core web-app is fully functional inside the shell. Store-grade hardening is
still to be added (tracked as follow-up work, none block the PWA):

- **Push notifications** — add `@capacitor/push-notifications` (FCM/APNs).
- **Biometric unlock** — add `@capacitor-community/biometric`.
- **Secure token/key storage** — the token currently persists exactly as the PWA
  does (Zustand + localStorage); move it to the OS keychain/keystore.
- **Splash screen / adaptive icons** — add `@capacitor/splash-screen` + store icons.
- **OTA / live updates** — optional Capgo or Ionic Appflow hosting.
